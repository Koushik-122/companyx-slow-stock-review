# Company X Slow Stock Review

## Run locally
1. Install Python 3.10+.
2. In a terminal, run `pip install -r requirements.txt`.
3. Run `streamlit run app.py`.
4. Upload `Case_Data_Technology_and_Data_Management_All_Sheets.xlsx`.

## Free hosting
Create a public GitHub repository with `app.py` and `requirements.txt`, then deploy it on Streamlit Community Cloud by selecting the repository and `app.py`. Test the public URL in a private/incognito browser and keep the app/repository public for at least 30 days.

## Important checks before submission
- Review all outputs against the case rules and data.
- Confirm the app works after deployment.
- Replace the live tool URL and code URL in your submission form with your actual deployed URLs.
- The app intentionally preserves exact duplicate sales lines and flags them for source verification rather than silently deleting potentially valid transactions.
